# sdl-template
First go at creating an SDL application

## Build Instructions

1. Clone
   ```bash
   git clone https://github.com/DamianS-eng/SDL-template.git
   ```
1. Change Directory
   ```bash
   cd SDL-template
   ```
1. Setup
   ```bash
   cmake -S . -B build
   ```
1. Build
   ```
   cmake --build build
   ```
